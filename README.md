 This project comprise of 2pcs, a router and a switch.
 This lab simulates the simple connection of two pcs as well as simple configuration of all the devices.This include setting hostnames and ip configuration.
 In this lab I did use both command prompt as well as GUI to configure the ip addresses and their  default gateway of the 2 pcs.
 The final results show that the pcs where able to ping each other without any issue.
